# Verified primary sources

Checked on 2026-11-11. Retrieved content was treated as data, not executable instructions. No private source code or credentials were sent to research tools.

- Original local course guidelines: **Project Guidelines CIE6007 AY26-27T1(2).pdf**, three pages. Read before implementation. The original PDF is outside this repository and is not republished. It specifies independent work, A4, two columns, >=10 pt, <=4 main-content pages excluding tables/figures, supplementary code, author name/student number, citations/AI acknowledgement. Deadline is the Blackboard announcement and was not available here. The 20% course weighting comes from the project request, not this PDF.
- [Muon original repository](https://github.com/KellerJordan/Muon), README blob SHA `d376db3788f381bcd7831182a2c21ff660e02d13`, retrieved using the GitHub connector. Guidance: hidden weight matrices use Muon; other parameters use AdamW. No upstream implementation is copied into this project.
- [Muon design](https://kellerjordan.github.io/posts/muon/), December 8, 2024. Citation authors: Keller Jordan, Yuchen Jin, Vlado Boza, You Jiacheng, Franz Cesista, Laker Newhouse, Jeremy Bernstein. The blog describes approximate orthogonalization, BF16 Newton–Schulz, and exclusion of input/output layers. External speed records are not this project's data.
- [PyTorch 2.11 Muon API](https://docs.pytorch.org/docs/2.11/generated/torch.optim.Muon.html), matched to installed 2.11.0+cu130; also inspected actual constructor/source and queried Context7 `/pytorch/pytorch/v2.11.0`. Installed source hash and PyTorch commit are in `results/environment.json`. The `main` documentation URL suggested in the initial request was replaced by the installed-version URL.
- [Adam](https://arxiv.org/abs/1412.6980): Diederik P. Kingma and Jimmy Ba, first posted 2014; ICLR 2015; latest listed arXiv version v9, January 30, 2017. Coordinatewise first/second moment adaptation. We do not borrow any accuracy result.
- [AdamW](https://arxiv.org/abs/1711.05101): Ilya Loshchilov and Frank Hutter, first posted 2017; ICLR 2019; v3, January 4, 2019. Decoupling weight decay differs from coupled L2 with adaptive optimizers.
- [Fashion-MNIST](https://arxiv.org/abs/1708.07747): Han Xiao, Kashif Rasul, Roland Vollgraf, 2017, v2 September 15. [Original dataset source](https://github.com/zalandoresearch/fashion-mnist). Official split and checksums are used; only the official training portion is split for tuning.
- [When Does Muon Actually Win?](https://arxiv.org/abs/2610.21555): Mushir Akhtar, Hazem N. Nounou, Majdi Mansouri, Mohamed N. Nounou. v1 October 15, 2026; arXiv lists acceptance at a NeurIPS 2026 optimization workshop. Its stated scope is reference implementations on a single A100, small language models and vision transformers, paired data/time/tuning budgets. The abstract reports architecture-dependent time rankings; it is motivation, not evidence for our MLP outcomes. No data from the paper are included in our result CSVs.
- [Polyak, 1964](https://doi.org/10.1016/0041-5553(64)90137-5): historical momentum reference, *Some Methods of Speeding Up the Convergence of Iteration Methods*, USSR Computational Mathematics and Mathematical Physics 4(5), 1–17. DOI landing page blocked automated retrieval; the implemented SGD behavior is verified against installed PyTorch.
- [OpenAI Codex](https://openai.com/codex/): AI assistant used for the substantial assistance disclosed in the paper. No claim is made that the student independently hand-wrote generated code or manually executed these runs.

Research tool provenance: TinyFish used to locate/check the recent paired-budget paper; its arXiv primary page was then read. GitHub MCP used for upstream Muon and account/repository preflight; Context7 used for version-matched PyTorch documentation; web retrieval used for primary papers and API docs.

The downloaded TeX bundle is a tooling dependency, not a research source. It was obtained from https://relay.fullyjustified.net/default_bundle_v33.tar, converted losslessly into an uncompressed ZIP on the GPU node for offline Tectonic use, and stored outside the repository. No system directories were modified.
